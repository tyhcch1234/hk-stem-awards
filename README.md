# 香港學界科研現場 · HK Student Research Index

線上版：**https://tyhcch1234.github.io/hk-stem-awards/**

一個靜態網頁，整理 2024—2026 年間香港中小學生在科學與資訊科技比賽中的 12 件得獎作品，逐件拆解它們的**理念、創新之處、獨特之處、關鍵技術**，並附上官方資料來源與影片。

> 12 件作品 · 12 間學校 · 6 項比賽 · 4 個日內瓦國際發明展獎項

## 內容

- **作品牆**：可按學段（小學／中學）、範疇（生物醫學、材料與環保、輔助科技、人工智能、健康科技、智能裝置）、年份篩選；點擊卡片開啟詳情。
- **觀察**：把 12 件作品攤開後整理出的四條共同線索，每點均標註對應作品。
- **影片**：25 秒開場影片（程式生成、無聲循環），以及主辦機構發布的賽事影片連結。
- **比賽**：六項比賽的主辦機構、規模與晉升關係。
- **方法**：區分「可核實事實」與「編輯觀察」，並說明圖片與影片的性質。

## 資料核實

獎項名稱、學校、作品名稱以主辦機構公佈的得獎名單或官方新聞稿為準；技術細節取自主辦方、學校或具名媒體報道。每件作品在詳情頁均附來源連結。

主要來源：

- 香港學生科學比賽 2025 得獎名單（香港青年協會創意教育組）
- 香港創新基金：創科展隊伍於日內瓦國際發明展獲獎
- 香港教育城：學生創新大賽結果
- 橙新聞：全港小學生運算思維比賽 2025
- TOPick：循道學校日內瓦發明展奪金
- 香港01：啓思小學 AI 創科比賽
- 香港商報：第 27 屆香港青少年科技創新大賽

## 圖片與影片聲明

- 所有作品影像均為按研究主題生成的 **AI 概念示意圖**，並非實際作品照片，也不應視為對作品外觀的準確描述。
- 開場影片由本專案以程式生成（Pillow + ffmpeg）。
- 賽事影片連結至主辦機構的官方社交平台發布，版權屬原發布者所有。

## 結構

```
index.html
assets/
  css/style.css
  js/data.js      # 作品與比賽資料
  js/app.js       # 篩選、詳情、動效
  img/*.webp      # AI 概念示意圖（已壓縮）
  video/opening.mp4
```

無建置步驟、無外部依賴（只載入 Google Fonts），可直接以任何靜態伺服器開啟：

```bash
python3 -m http.server 8000
```
